2. Description of Service

EventPing is a browser extension that:

  • Scans your Gmail for event registration links
  • Detects registration forms on websites you visit
  • Stores URLs locally for your reference
  • Sends notifications about pending registrations

4. Gmail API Usage

The Extension uses Gmail API with read-only access (gmail.readonly). You grant the Extension permission to:

  • Read unread emails matching your configured filters
  • Extract URLs from email content

You can revoke this permission anytime at: https://myaccount.google.com/permissions
